# Obsidian 0.0.1 - Phase 0

This is the first engineering milestone for Obsidian. It is a bootstrap release, not a performance renderer release.

## Included

- Fabric 26.2 client bootstrap.
- Vulkan-only backend validation.
- attachment to Minecraft's active Blaze3D `GpuDevice`.
- GPU/backend capability logging.
- renderer conflict detection.
- configuration scaffolding.
- clean `RendererBridge` boundary for the renderer work that follows.

## Important

Obsidian does **not** replace vanilla terrain rendering in Phase 0, so this release is not expected to increase FPS. Its purpose is to validate lifecycle integration and Vulkan backend assumptions before Phase 1 begins allocating and submitting Obsidian-owned GPU resources.

## Test target

Initial reference system:

- Windows 11
- AMD Ryzen 5 5600X
- AMD Radeon RX 6800 XT
- 16 GB DDR4
- Minecraft Java 26.2
- Fabric Loader 0.19.3+
- Java 25

Select Vulkan in Minecraft's Graphics API setting before launching with Obsidian.
