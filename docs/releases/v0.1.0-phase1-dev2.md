# Obsidian 0.1.0 Phase 1 dev2

Development validation milestone for frame contexts and safe GPU resource lifetime.

Validated on the reference Windows 11 / AMD Radeon RX 6800 XT system with Minecraft 26.2 Vulkan.

Implemented and validated:

- three-slot preallocated frame-context ring with monotonically increasing serials;
- frame serials used as bookkeeping only, never as proof of GPU completion;
- real `GpuFence` completion checks;
- zero-timeout steady-state fence polling;
- deferred GPU resource destruction;
- bounded shutdown cleanup;
- one-shot 64-byte GPU resource lifetime validation probe;
- clean world entry and shutdown with `retiredResources=1`, `releasedResources=1`, `pending=0`.

This is a development milestone, not a public release target. Terrain rendering remains owned by Minecraft and Obsidian does not yet upload terrain geometry.
